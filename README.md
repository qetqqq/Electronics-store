Магазин техники (Electronics Store)

Десктопное приложение для управления каталогом техники и оформления заказов, разработанное на Python с использованием графической библиотеки PySide6 (Qt) и базы данных MySQL.

Функционал программы:
* Авторизация и регистрация: Вход в систему по логину и паролю, а также возможность создания нового аккаунта прямо из интерфейса.
* Просмотр товаров: Отображение каталога техники с указанием модели, категории, производителя и цены.
* Поиск и фильтрация: Поиск по названию модели в реальном времени и фильтрация по категориям товаров.
* Оформление заказов: Возможность купить товар (добавить в базу данных в качестве заказа).
* История заказов: Личный кабинет "Мои заказы", где отображаются только покупки текущего авторизованного пользователя.
* Панель администратора: Добавление новых товаров в каталог и удаление существующих.
* Смена цветовой темы: Динамическое изменение цвета фона главного окна.

Технологии:
* Язык: Python 3.9+
* GUI: PySide6 (Qt for Python)
* База данных: MySQL 8.0+
* Драйвер БД: mysql-connector-python

Установка и запуск
1. Подготовка базы данных
1. Откройте MySQL Workbench.
2. Выполните SQL-скрипт из файла database.sql (он создаст базу tech_shop_db, все таблицы и добавит тестовые данные).

2. Установка зависимостей
Откройте терминал в папке с проектом и установите необходимые библиотеки:
pip install PySide6==6.7.3 mysql-connector-python
(Важно: версия PySide6 6.7.3 выбрана для совместимости с Python 3.9)

3. Настройка подключения
Откройте файл main.py и в блоке DB_CONFIG (в начале файла) укажите пароль от вашей базы данных MySQL:
DB_CONFIG = {
    "host": "127.0.0.1",
    "user": "root",
    "password": "ВАШ_ПАРОЛЬ",
    "database": "tech_shop_db"
}

4. Запуск
В терминале выполните:
python main.py
